# Geospatial

**Menu label:** Geospatial

Mapbox map of every city Muse Create has delivered to, with lines radiating from the studio in Raipur.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Map page, inline Mapbox/Turf logic, token gate |

## Setup

Add a Mapbox access token near the top of `index.html` before the map will load.

## Open

`geospatial/` from the repo root.
