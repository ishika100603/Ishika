# 3D Canvas.1

**Menu label:** 3D Canvas.1

Flat artworks as draggable, stackable cubes on a mirror floor. Build your own composition in 3D.

## Files

| File / folder | Purpose |
|---------------|---------|
| `index.html` | Page shell and controls copy |
| `scene1.js` | Three.js scene, physics, interaction |
| `canvas3-cubes.js` | Cube texture path list |
| `images/` | 14 artwork textures for cube faces |

## Open

`3d-canvas-1/` from the repo root.
